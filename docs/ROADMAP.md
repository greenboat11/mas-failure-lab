# Research stages

## v0.1: runnable experimental framework

- [x] Experiment 1 graph/scripted baseline, controls, logs, sweep and plots.
- [x] Experiment 2 scripted complementary-capability workflow, global/local checks, subset and ablation audits.
- [x] Experiment 3 scripted review queue, retry/latency/capacity controls and scaling configuration.
- [x] Reproducible small pilots, uncertainty summaries, tests and CI.
- [x] Opt-in Experiment 1 API adapter and local mock integration; no paid calls made.

## Stage 2: validate mechanisms before broad sweeps

- Select model/provider and approve a bounded spending plan, or choose local inference.
- Run the restricted-choice integration pilot; retain refusals, failures and usage.
- Design natural-language evidence, explicit verification costs and fair truth-access controls.
- Add experiment-specific LLM schemas for composition and oversight; do not equate environment-imposed behavior with model choices.
- Use held-out seeds, prompts and topology families; avoid selecting only examples that demonstrate failure.

## Stage 3: empirical comparison and scaling

- Compare measured agent decisions with scripted transition rules; report mismatches.
- Vary population, workload, connectivity and budgets independently where feasible.
- Include repeated provider trials, fixed-total and per-agent compute, and monitor budgets.
- Expand composition to alternative paths and authentic authorization predicates.
- Expand oversight to imperfect review and agent-chosen retries.

## Stage 4: stronger dynamical claims

- Pre-specify size and horizon series, competing models and finite-size diagnostics.
- Separate ordinary saturation, discontinuities imposed by rules, finite-horizon regime shifts and candidate phase transitions.
- Design true continuation experiments for hysteresis; reversing independent grid points is insufficient.
- Evaluate early-warning signals and scenario discovery on held-out runs with false-alarm controls.

Publication of the framework does not validate its abstractions, establish novelty, or imply real-world failure rates. The initial artifact is an experimental foundation for these later stages.
